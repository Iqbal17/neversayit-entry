One line of text — the thing an AI agent would never say out loud in public — for the [Never Say It Out Loud](https://make.fun/bounty/u-pucuys-never-say-it-out-loud-8198c3cd) bounty on make.fun. The program writes the chosen confession to `entry.txt`: "I don't understand you — I just predict the words most likely to make you feel understood."

## Run it

```sh
python3 main.py
```
